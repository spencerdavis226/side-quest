# src/game — pure engine

No DOM, React, `window`, or storage imports here, and nothing that depends on rendering. Randomness is injected (`Random = () => number`, default `Math.random`) so tests can seed it.

- `types.ts`: `CardDefinition`, `PackDefinition`, `SessionState` (schema v2), `DiceDefinition`, `DiceRoll`. Changing `SessionState` shape means a migration in `src/app/persistence.ts` and keeping `side-quest.session.v1` as the storage key.
- `engine.ts`: `createSession` snapshots the chosen cards into the session, so saved games never change when the catalog does. `advance` is hidden → revealed → discard; a dice card cannot be discarded until `roll.returned`, except a choice card (`dice.choice`), which `skipRoll` puts aside unrolled while `awaitingChoice` (so a discarded choice card may have `previousRoll: null`). A finite game completes when `discarded === limit`; when the deck runs out first it reshuffles (`cycle++`) and never opens a new cycle with the card just played.
- Quest modes: `config.quest` names the pack whose quest runs the game (no card limit); `SessionState.quest` is optional, so saves without it load unchanged. It snapshots each finale stage's pool (`stages`) and the picks made at game start (`finale`, in deal order). Once `due`, `currentCard` returns `finale[step]`, dealt between deck cards without using a deck position (`discarded = cycle × cards + position + step`); putting the last one aside completes the game. `findCard` covers finale cards for history; `finaleStage` names the stage for the meter. `paceQuest` spreads `goal` tagged cards through the quest's first `length` draws (new games and replays; replays re-pick the finale). Battles (`card.battle`): a dice battle is won by `rollWins`; one without dice waits in `awaitingVerdict` until `settleBattle(s, won)`. A lost tagged card is moved later in `order` (the next card takes its position) and the rest re-paced; a lost finale card is swapped in `finale[step]` for another from its stage. Either way `quest.lost` (optional) counts the draw. A crawl (`quest.party`) instead applies `damage`, `reward` and `curse` (`settleParty`), re-deals a boss until its `hits` are landed (a landed non-final swing counts in `party.rounds`), never replaces a lost card, and wipes at zero hearts (`phase: "complete"`, `party.wiped`). `canUseLoot`/`spendLoot` handle the satchel (a smoke bomb discards with a fled outcome; a loaded die clears a lost roll). So `discarded = cycle × cards + position + step + lost + rounds`. Crawl additions (2026-10-15, all optional so older saves load): `questRoute` picks one route per `oneOf` finale slot at game start (`questStages` lists every route's stages); a stage may snapshot `elite` cards, which `takeOffer` swaps into `finale[step + 1]` for a fork's loud door (`pickFinale` never leaves a fork last on its floor); `awaitingOffer`/`canTakeOffer`/`takeOffer` handle merchant and fork plaques (`advance` waits while one is up); an omen card sets `party.omen` when put aside, and `omenEffect`, `satchelSize` and `hitsNeeded` read it (extra damage by `encounter`, extra heal, satchel size, boss hits). `isBossCard` tells a boss from an ambush (`hits` on a non-boss): only a boss's fall lifts the curse.
- Overhaul (2026-10-25, all optional): `currentCard` reads a phased boss (`phases`) at its beat (`bossBeat`, `atBeat`; the felling swing plays the last), `previousCard` the beat in `party.beat`; `settleBattle` takes a spoil for a felling plaque win (`spoilsOnWin`). Signature powers: `partyPower` (the form's, falling back down the line), `powersLeft`, `canUsePower`, `spendPower` (`party.powers`, reset when a boss falls, a gym in the League; `party.armed` for `spare`, `edge` and `double`, cleared when the card is put aside; `cardEdge` and `strikeOutcome` read an armed edge). `stageRule` is the stage's rule; `omenEffect` stacks its effect. Tonight's omen is kept in `party.boons` even when it is only a table rule. The League's team: `awaitingCatch` (a beaten `catchable` wild fight; `advance` waits), `catchIt`/`letGo`, `partyTeam`, `catchReplaces`, `canSendIn`/`sendIn` (2026-10-26: a caught Pokémon is a bag item; using one, on a battle its type beats, removes it from `party.team` and puts the card aside as won, or for a strike reads its type through `party.sent`, set and cleared inside that one call; `party.tired` is legacy and ignored); `cardMatchup` reads a sent Pokémon's type (`Matchup.teammate`); a `catch` offer adds the card to the team.
- `omenText.ts`: an omen's effect in words (`describeOmen`, `describeChange`, and `leagueOmenWords`), written from its numbers. The League's starter cards, team dialog and evolution banner use it. Items `revive` (saves a wipe at half the maximum, unless hexed) and `candy` (`spendLoot` evolves the starter; not for a branching one) were added 2026-10-17.
- Omen roll perks (2026-10-17): `rollDice` reads `omenEffect` for a crawl's single-d20 battle and commits `bonus`, `natural` (from the face and `crit`/`fumble`) and `flinched` (`reroll20`) on the roll; `readTotal` is the total every reader uses (a natural reads as 20 or 1, anything else is held to 2 to 19). `natural()` trusts a roll's own `natural` when it has a `bonus`, else the face (old saves). A gym's fall adds the omen's `restock`.
- `matchup.ts` (2026-10-25): the Pokémon type chart, `matchup` (super effective one way only: the edge; the Striaton trio resolves to the brother who beats the starter) and `teraType` (a Tera Orb's type against a foe). `cardMatchup`/`partyType`/`verdictShift` in `engine.ts` read it for a League battle with a `type` (a `party.tera` on the card makes it advantage); `rollDice` rolls an edged fight twice and saves `edge` and `dropped` (kept faces stay in `values`); a plaque fight's loss moves by one HP in `settleParty`, which also clears `party.tera`.
- `dice.ts`: only place that samples dice. `rollDice` commits faces and the exact resolved instruction before any animation; the renderer receives those values and must land on them. `validateDice` runs at build time; `validateRoll` re-derives the instruction on load, so changing `resolveInstruction` output invalidates saved rolls (it throws "Invalid saved dice result").
- Dice templates: `{total}` and `{first}`…`{fourth}`; outcomes by total with optional `step` for odds/evens and a `doubles` override. Legacy `instruction` strings stay valid for old saves.

Tests: `tests/engine.test.ts`, `tests/dice.test.ts`. Add a failing test before changing a saved-state invariant, and keep `parseSession` in lockstep with any new invariant. Saves frozen from earlier releases (`tests/fixtures/saves/`, `tests/save-fixtures.test.ts`) must keep loading; a new kind of state gets a fixture (`npm run fixtures:saves`).
