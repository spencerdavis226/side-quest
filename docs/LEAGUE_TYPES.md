# League types

Generated by `npm run league:types` from the cards; never hand-edit. Types are set in `src/content/league/types.ts` (owner, 2026-10-25). A dice fight against a type the starter is super effective on rolls double the dice and keeps the best (a d20 the better of two, 2d6 the two highest of four); one super effective on the starter keeps the worst. A fight settled with plaques costs 1 HP less or more when lost. The edge goes to whichever side's type is super effective against the other's; anything else is even (`src/game/matchup.ts`).
